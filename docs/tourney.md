# Architecture tournament (per component)

`tools/tourney/` evolves one RTL component at a time with LLM agents, in the style of
`auto-arch-tournament`. Each component has its own champion branch; every round, K agents propose
and implement a change in parallel, the changes are gated (correctness first, then performance,
then synthesis), and the best one that passes the accept rule becomes the new champion.

```
make tourney COMP=otpu_coll N=1 K=1              # 1 round, 1 slot, claude agents, yosys eval
make tourney COMP=otpu_mxu N=5 K=4 AGENT=codex   # 5 rounds x 4 parallel slots with codex
make tourney-baseline COMP=otpu_vpu              # measure the champion only (no agents)
make tourney-report [COMP=otpu_coll]             # REPORT.md + progress.png per component
make test-tourney                                # harness unit tests
```

Components (`tools/tourney/components/*.yaml`, generated by `gen_components.py`): `otpu_seq`,
`otpu_mxu`, `otpu_quant`, `otpu_vpu`, `otpu_tmem`, `otpu_dma`, `otpu_actram`, `otpu_coll`,
`otpu_axi_dram`, and `otpu_fp` (the shared fp32 operators). Each config lists the files the agent
may change, the synthesis top(s) with board parameters, the target clock, and the test subsets.

## One round

1. **Champion.** Branch `tourney/<comp>`, created from `main` (`BASE=`) the first time
   (`ARGS=--reset` recreates it). Its metrics are measured once per commit and cached in
   `tools/tourney/runs/<comp>/champion.json`.
2. **Slots** (K in parallel threads). Each gets a git worktree `.tourney/<comp>/<id>` on branch
   `tourney-slot/<comp>/<id>` off the champion; `build/` (Verilator cache, keyed by source hash)
   and `models/` are symlinked from the main checkout.
3. **Hypothesis agent** — sees the component source, the champion's numbers and critical path,
   the recent log, `LESSONS.md`, and a focus category (timing / area / memories / structure,
   rotated per slot). Writes only `HYPOTHESIS.md`; anything else fails the slot.
4. **Implementation agent** — edits only the allowed files, lints, runs one quick test, writes
   `IMPLEMENTATION.md`. No commits.
5. **Gates**, in order; the first failure ends the slot as `broken: <gate>: <output tail>`:
   | gate | what | time |
   |---|---|---|
   | sandbox | only the component's files (plus the two notes) changed; at least one RTL change | 0 s |
   | lint | Verilator lint of `otpu_top` (D=128, MCOLS=2, AXI) and `otpu_board` | ~10 s |
   | fast | bit-exact RTL vs ISA subset (`tests/test_rtl.py`, plus component extras) | 1-3 min |
   | board | same with `OTPU_UARCH=board OTPU_AXI=1 OTPU_BOOT=1` (board micro-arch, AXI DRAM, boot) | 1-3 min |
   | perf | Qwen3-0.6B decode proxy (`tools/perf_qwen.py --layers 2 --bw 80`, deterministic); ≤ +0.2% cycles vs champion; skipped without weights | ~1 min |
   | synth | component synthesis → LUT, LUTRAM, FF, DSP, BRAM36/18, logic ns, est fmax | 10 s - 10 min |
6. **Accept rule** (`tools/tourney/accept.py`), vs the champion:
   - **A (area):** est fmax ≥ target (110 MHz) and area-eq −1% or better; or
   - **B (speed):** est fmax +3% or better with area-eq at most +1%.

   `area_eq = LUT + LUTRAM + 0.5·FF + 40·DSP + 80·BRAM36 + 40·BRAM18`. Yosys fmax estimate:
   `1000 / (1.6·logic_ns + 0.5)`. A slot with any failed gate is never accepted. A component
   below target (e.g. `otpu_coll` at ~75 MHz) can only win on rule B until it reaches the target.
7. **Merge.** Of the accepted slots, the largest (area gain + fmax gain) is committed in its
   worktree (RTL files only, not the notes) and the champion branch is fast-forwarded to it with
   `git update-ref` (compare-and-swap on the old champion). `main` is never touched; merging a
   champion into `main` is a human decision (`git merge tourney/<comp>`).
8. **Scribe** — one line per slot appended to `runs/<comp>/LESSONS.md` (falls back to a template
   line if the agent fails). Every slot appends one JSON record to `runs/<comp>/log.jsonl`:
   hypothesis, implementation notes, files, diff stat, test summaries, perf cycles, metrics,
   outcome and reason, models and efforts, per-role wall time and token usage / cost, per-gate
   seconds. Agent transcripts go to `runs/<comp>/agents/` (git-ignored).

Slot worktrees and branches are removed after the round (`ARGS=--keep` keeps them).

## Evaluators

- `EVAL=yosys` (default, works today): Yosys + slang, `synth_xilinx -family xc7 -flatten -abc9`,
  then `sta` with the Xilinx cell timing models. Logic-only; the fmax is an estimate to *rank*
  candidates, not signoff. Uses `--allow-use-before-declare` (for sources that declare a signal
  after use).
- `EVAL=vivado` (**untested** — Vivado is not installed yet): out-of-context synth, place, route
  on xc7k480tffg1156-2 through `~/bonetto/vivado-docker/vivado` (override with `VIVADO=`),
  10 ns clock; utilization and post-route WNS → fmax. Check the report parsing
  (`synth.parse_vivado_util`) on the first real run. The champion cache is per evaluator.

`otpu_fp` synthesizes `otpu_fadd` and `otpu_fmul` and weights them by their approximate instance
counts at the board configuration (64 / 78), so its fitness tracks the whole design's fp cost;
its test gates are the whole of `tests/test_fp.py` + `tests/test_rtl.py`.

## Agents, models and effort

`AGENT=claude` (default) runs `claude -p ... --permission-mode acceptEdits --allowedTools <lint/test/read-only list> --disallowedTools WebFetch WebSearch --output-format
stream-json --model M --effort E` in the slot worktree; `AGENT=codex` runs `codex exec
--sandbox workspace-write --json --model M -c model_reasoning_effort=E`. The agents run
unattended with least privilege: edits auto-accepted in the slot worktree only, shell limited
to lint/test/read-only commands, no network tools, everything else denied. The sandbox gate
then checks that only the component's files changed.

| role | model (`MODEL_*`) | effort (`EFFORT_*`) |
|---|---|---|
| hypothesis | `MODEL_HYP=claude-opus-5-5` | `EFFORT_HYP=high` |
| implementation | `MODEL_IMPL=claude-opus-5-5` | `EFFORT_IMPL=high` |
| scribe | `MODEL_SCRIBE=claude-opus-5-5` | `EFFORT_SCRIBE=low` |

Efforts: `low | medium | high | xhigh | max` (codex maps xhigh/max to high). With `AGENT=codex`
and no `MODEL_*`, codex uses its own default model. Any of these may be a comma list, assigned
round-robin to the K slots, so one round can compare settings:

```
make tourney COMP=otpu_mxu N=3 K=4 EFFORT_IMPL=high,xhigh
```

`make tourney-report` then shows slots, accept rate, cost per slot and per accepted change, and
agent wall time per role, per implementation model and effort.

## Cost

Measured on the smoke round (`otpu_coll`, 1 slot, Opus 5.5 at high effort, CLI-reported cost):
hypothesis 111 s, implementation 98 s, scribe 5 s, **$1.12 total**; gates 72 s (lint 2 s, fast
10 s, board 9 s, perf 46 s, synth 5 s) with a warm Verilator cache. The whole slot took 4.7 min.
Bigger units cost more: `otpu_mxu`/`otpu_vpu`/`otpu_seq` have 3-10x the source for the agents
to read and minutes of synthesis, and `otpu_fp` gates on the full RTL suite (~30 min+). Budget
roughly $1-5 and 5-45 min per slot; `make tourney-report` gives the real numbers per model. A run of N rounds × K slots costs about N·K slot-costs; wall time is
about N × (slowest slot), as slots run in parallel (mind the machine's cores: every slot runs
its own Verilator builds).

## Smoke round result (2026-09-23)

`make tourney COMP=otpu_coll N=1 K=1` from main 9a8e6b1: the agent replaced GATHER's three
address multiplies (9 DSP48s chained into the write address) with running-sum address registers
and registered the masks. All gates passed, perf proxy unchanged (1,912,335 cycles), and the change
was accepted on rule A: LUT 1325→1165, FF 262→280, DSP 9→0, logic 8.06→4.57 ns, est fmax
75→128 MHz, area-eq 1816→1305 (−28%). Champion `tourney/otpu_coll` = b3af1b5 (not merged into
main).

```
tools/tourney/agents.py         claude/codex runtime, prompts, model/effort selection, usage

tools/tourney/runs/<comp>/      champion.json, log.jsonl, LESSONS.md, REPORT.md, progress.png
```
