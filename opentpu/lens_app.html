How to read this view
  • Blocks are the hardware units; data flows along the grey paths. Moving dashes mean data is moving on that path right now.
  • Outline colour = state of the unit at this moment (legend below): green busy, red stalled on DRAM, purple lost TMEM arbitration, orange blocked, amber waiting for a dependency, grey idle.
  • The roofline gap bar (right) is DRAM port B in the current window of cycles: teal = streaming (good), everything else = why it is not streaming.
  • The goal: port B streaming every cycle (the DRAM roofline). Find the unit or cause that keeps it from doing so.
  • Hover anything for what it is, how it works, its live state and what would help; click (or tap) to pin the explanation. space play/pause, ←/→ step.
